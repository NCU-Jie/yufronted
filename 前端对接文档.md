# 图书预约到馆提醒 - 前端对接文档

## 功能说明

当图书归还后，系统会自动：
1. 检索预约记录，将首位预约状态改为"待领取(3)"
2. 创建站内信提醒
3. 通过 WebSocket 推送实时通知给读者

---

## 一、WebSocket 连接

### 1.1 连接地址

```
ws://localhost:8080/ws/reader/{readerId}
```

**说明：**
- `readerId`：从 JWT token 中解析出的读者ID
- 读者登录后立即建立 WebSocket 连接
- 建议在路由守卫或全局组件中建立连接

### 1.2 连接示例代码

```javascript
// utils/websocket.js

class WebSocketManager {
  constructor() {
    this.ws = null;
    this.readerId = null;
    this.reconnectTimer = null;
    this.heartbeatTimer = null;
    this.reconnectAttempts = 0;
    this.maxReconnectAttempts = 5;
  }

  /**
   * 建立 WebSocket 连接
   * @param {Number} readerId - 读者ID
   */
  connect(readerId) {
    if (this.ws && this.ws.readyState === WebSocket.OPEN) {
      console.log('WebSocket 已连接');
      return;
    }

    this.readerId = readerId;
    const wsUrl = `ws://localhost:8080/ws/reader/${readerId}`;
    
    console.log('正在建立 WebSocket 连接...', wsUrl);
    this.ws = new WebSocket(wsUrl);

    this.ws.onopen = () => {
      console.log('WebSocket 连接成功');
      this.reconnectAttempts = 0;
      this.startHeartbeat();
    };

    this.ws.onmessage = (event) => {
      this.handleMessage(event.data);
    };

    this.ws.onclose = () => {
      console.log('WebSocket 连接关闭');
      this.stopHeartbeat();
      this.reconnect();
    };

    this.ws.onerror = (error) => {
      console.error('WebSocket 错误:', error);
    };
  }

  /**
   * 处理接收到的消息
   * @param {String} data - 消息数据
   */
  handleMessage(data) {
    try {
      const message = JSON.parse(data);
      console.log('收到 WebSocket 消息:', message);

      switch (message.type) {
        case 'reserve_notify':
          this.handleReserveNotify(message);
          break;
        default:
          console.log('未知消息类型:', message.type);
      }
    } catch (error) {
      console.error('消息解析失败:', error, data);
    }
  }

  /**
   * 处理预约到馆通知
   * @param {Object} message - 消息内容
   */
  handleReserveNotify(message) {
    console.log('预约到馆提醒:', message);
    
    // 1. 显示弹窗通知
    this.showNotification(message);

    // 2. 触发全局事件，通知其他组件
    if (typeof window !== 'undefined') {
      window.dispatchEvent(new CustomEvent('reserve-notify', { 
        detail: message 
      }));
    }

    // 3. 更新未读消息数（通过 Vuex/Pinia）
    if (window.__app__) {
      const store = window.__app__.$store || window.__app__._instance.proxy.$store;
      if (store && store.dispatch) {
        store.dispatch('notice/incrementUnreadCount');
      }
    }
  }

  /**
   * 显示桌面通知
   * @param {Object} message - 消息内容
   */
  showNotification(message) {
    // 检查浏览器是否支持通知
    if ('Notification' in window) {
      if (Notification.permission === 'granted') {
        this.sendDesktopNotification(message);
      } else if (Notification.permission !== 'denied') {
        Notification.requestPermission().then(permission => {
          if (permission === 'granted') {
            this.sendDesktopNotification(message);
          }
        });
      }
    }
  }

  /**
   * 发送桌面通知
   * @param {Object} message - 消息内容
   */
  sendDesktopNotification(message) {
    const notification = new Notification('📚 预约到馆提醒', {
      body: `您预约的《${message.bookName}》现已到馆，请在 ${message.deadline} 前到馆完成借阅！`,
      icon: '/favicon.ico',
      tag: `reserve-${message.reserveId}`
    });

    notification.onclick = () => {
      window.focus();
      // 跳转到预约详情页或确认借阅页面
      window.location.href = `/reader/reserve/detail/${message.reserveId}`;
      notification.close();
    };
  }

  /**
   * 断线重连
   */
  reconnect() {
    if (this.reconnectAttempts >= this.maxReconnectAttempts) {
      console.log('达到最大重连次数，停止重连');
      return;
    }

    if (this.reconnectTimer) {
      clearTimeout(this.reconnectTimer);
    }

    this.reconnectAttempts++;
    const delay = Math.min(1000 * Math.pow(2, this.reconnectAttempts), 30000);
    
    console.log(`${delay}ms 后尝试第 ${this.reconnectAttempts} 次重连...`);
    
    this.reconnectTimer = setTimeout(() => {
      console.log('正在重连...');
      this.connect(this.readerId);
    }, delay);
  }

  /**
   * 心跳检测
   */
  startHeartbeat() {
    this.heartbeatTimer = setInterval(() => {
      if (this.ws && this.ws.readyState === WebSocket.OPEN) {
        this.ws.send(JSON.stringify({ type: 'ping' }));
      }
    }, 30000); // 每30秒发送一次心跳
  }

  /**
   * 停止心跳
   */
  stopHeartbeat() {
    if (this.heartbeatTimer) {
      clearInterval(this.heartbeatTimer);
      this.heartbeatTimer = null;
    }
  }

  /**
   * 关闭连接
   */
  close() {
    if (this.reconnectTimer) {
      clearTimeout(this.reconnectTimer);
    }
    this.stopHeartbeat();
    if (this.ws) {
      this.ws.close();
      this.ws = null;
    }
  }
}

// 导出单例
export default new WebSocketManager();

```

## 二、站内信功能

### 2.1 API 接口

#### 获取我的站内信列表
```
GET /reader/notice/my/list
Headers: token: {jwt_token}
```

**响应示例：**
```json
{
  "code": 1,
  "msg": null,
  "data": [
    {
      "id": 1,
      "readerId": 5,
      "content": "您预约的图书《人类简史》现已到馆，请在2026-05-13 14:21:30前到图书馆完成借阅。",
      "isRead": 0,
      "createTime": "2026-05-10 14:21:30"
    }
  ]
}
```

#### 标记站内信为已读
```
PUT /reader/notice/read/{noticeId}
Headers: token: {jwt_token}
```

#### 删除站内信
```
DELETE /reader/notice/{noticeId}
Headers: token: {jwt_token}
```

### 2.2 站内信组件示例（Vue3）

```vue
<!-- components/NoticeList.vue -->
<template>
  <div class="notice-container">
    <div class="notice-header">
      <h3>站内消息</h3>
      <span class="unread-count" v-if="unreadCount > 0">
        {{ unreadCount }} 条未读
      </span>
    </div>

    <div class="notice-list">
      <div 
        v-for="notice in noticeList" 
        :key="notice.id"
        class="notice-item"
        :class="{ 'unread': notice.isRead === 0 }"
      >
        <div class="notice-content">
          <p class="notice-text">{{ notice.content }}</p>
          <span class="notice-time">{{ formatTime(notice.createTime) }}</span>
        </div>
        
        <div class="notice-actions">
          <button 
            v-if="notice.isRead === 0"
            @click="handleMarkAsRead(notice.id)"
            class="btn-read"
          >
            标记已读
          </button>
          <button 
            @click="handleDelete(notice.id)"
            class="btn-delete"
          >
            删除
          </button>
        </div>
      </div>

      <div v-if="noticeList.length === 0" class="empty-state">
        <p>暂无消息</p>
      </div>
    </div>
  </div>
</template>

<script setup>
import { ref, onMounted, onUnmounted } from 'vue';
import { getNoticeList, markNoticeAsRead, deleteNotice } from '@/api/notice';
import dayjs from 'dayjs';

const noticeList = ref([]);
const unreadCount = ref(0);

// 获取站内信列表
const fetchNotices = async () => {
  try {
    const res = await getNoticeList();
    noticeList.value = res.data;
    unreadCount.value = res.data.filter(n => n.isRead === 0).length;
  } catch (error) {
    console.error('获取站内信失败:', error);
  }
};

// 标记为已读
const handleMarkAsRead = async (noticeId) => {
  try {
    await markNoticeAsRead(noticeId);
    const notice = noticeList.value.find(n => n.id === noticeId);
    if (notice) {
      notice.isRead = 1;
      unreadCount.value--;
    }
  } catch (error) {
    console.error('标记已读失败:', error);
  }
};

// 删除站内信
const handleDelete = async (noticeId) => {
  if (!confirm('确定删除此消息吗？')) return;
  
  try {
    await deleteNotice(noticeId);
    noticeList.value = noticeList.value.filter(n => n.id !== noticeId);
    const notice = noticeList.value.find(n => n.id === noticeId);
    if (notice && notice.isRead === 0) {
      unreadCount.value--;
    }
  } catch (error) {
    console.error('删除失败:', error);
  }
};

// 格式化时间
const formatTime = (time) => {
  return dayjs(time).format('YYYY-MM-DD HH:mm:ss');
};

// 监听 WebSocket 消息，自动刷新列表
const handleReserveNotify = () => {
  fetchNotices();
};

onMounted(() => {
  fetchNotices();
  window.addEventListener('reserve-notify', handleReserveNotify);
});

onUnmounted(() => {
  window.removeEventListener('reserve-notify', handleReserveNotify);
});
</script>
```

```vue
    await cancelReserve(reserveId);

    fetchReserveList();
  } catch (error) {
    ElMessage.error('取消失败');

    0: '待处理',

  const map = {
    0: 'info',
    1: 'success',
    2: 'danger',
    3: 'warning'
  };
  return map[status] || 'info';
};
```

## 五、完整使用流程

### 5.1 用户操作流程

1. **读者登录**
   - 登录成功后，建立 WebSocket 连接
   - 加载站内信列表，显示未读消息数

2. **接收预约到馆通知**
   - WebSocket 收到推送消息
   - 显示桌面通知（需用户授权）
   - 导航栏徽章数字 +1
   - 自动刷新站内信列表

3. **查看站内信**
   - 点击导航栏消息图标
   - 查看预约到馆提醒内容
   - 显示领取截止时间

4. **到馆确认借阅**
   - 点击"确认借阅"按钮
   - 系统生成借阅记录
   - 预约状态变更为"已完成"
   - 库存已预留，直接借阅成功

5. **超时处理**
   - 3天内未到馆，系统自动取消预约
   - 释放预留库存
   - 通知下一位预约者

### 5.2 技术要点

- ✅ WebSocket 断线自动重连
- ✅ 心跳检测保持连接
- ✅ 消息去重处理（tag标识）
- ✅ 桌面通知权限管理
- ✅ 全局事件总线通知
- ✅ 未读消息数实时更新
- ✅ 预约状态实时刷新

## 六、注意事项

1. **HTTPS 环境**
   - 生产环境建议使用 `wss://` 协议（WebSocket Secure）
   - 开发环境可以使用 `ws://` 协议

2. **跨域问题**
   - WebSocket 不受同源策略限制
   - 但需要确保端口正确

3. **消息可靠性**
   - WebSocket 消息不保证送达
   - 重要消息应配合站内信存储
   - 前端应定期轮询未读消息

4. **性能优化**
   - 避免频繁创建 WebSocket 连接
   - 使用单例模式管理连接
   - 页面切换时保持连接

5. **兼容性**
   - 现代浏览器都支持 WebSocket
   - IE10+ 支持 WebSocket
   - 移动端浏览器普遍支持

## 八、常见问题

**Q1: WebSocket 连接失败？**
- 检查端口是否正确（8080）
- 检查后端是否正常运行
- 检查防火墙设置

**Q2: 收不到推送消息？**
- 检查 WebSocket 连接状态
- 查看浏览器控制台是否有错误
- 确认后端 notifyReservers 方法是否正确调用

**Q3: 桌面通知不显示？**
- 检查浏览器通知权限
- 在设置中允许网站通知
- 移动端可能不支持桌面通知

**Q4: 断线后不重连？**
- 检查 reconnect 逻辑
- 确认最大重连次数设置
- 查看控制台日志
